# neuroskill

Same skill. Clearer.

`tdah-remix` turns any Claude skill into an ADHD-friendly version. Keeps the logic, tools and constraints. Changes only how it talks — short, scannable, no walls of text.

> by people with ADHD — for people with ADHD

**Install**

```bash
mkdir -p ~/.claude/skills/tdah-remix && curl -fsSL https://raw.githubusercontent.com/raulmoracode/neuroskill/main/SKILL.md -o ~/.claude/skills/tdah-remix/SKILL.md
```

**Use**

1. Have both skills installed (remix + skill to remix)
2. Call remix → “make me a remix”
3. Call target skill → get remixed version back
